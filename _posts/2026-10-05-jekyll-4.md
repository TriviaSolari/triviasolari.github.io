Well, it's been barely a month and the site already looks almost completely different.

I found out while working on another GitHub Pages site that apparently the Ruby
gem that used to handle all of this (and that I was using before now) has been
abandoned or [otherwise unmaintained](https://github.com/github/pages-gem/issues/890)
for about two years now. Which is annoying, since [GitHub's documentation](https://docs.github.com/en/pages/quickstart)
for creating a site _still_ tells you to use a branch-based build process for this
that uses the unmaintained gem, as opposed to the modern workflow that uses GitHub
actions.

Either way, the site has been updated to use the modern process now, and along
the way I updated it to Jekyll 4, and swapped out to the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/)
theme, since the one I was using before had a pinned dependency that was only
available for Jekyll 3, and as far as I could tell, was also unmaintained.
